Plano de cortado

En esta sección se presenta el plano utilizado para fabricar las piezas del brazo robot 2D.

Aquí se documentan la distribución de las piezas, las dimensiones utilizadas y la preparación del archivo para el proceso de corte.

Se utilizó un plano encontrado en instructables.com para la construcción de este mecanismo.

Entendiendo que tenía el archivo dimensiones estandarizadas de 20 x 30cm, pudimos identificar las dimensiones de cada pieza a escala física / real.

Alcance del plano recibido

El PDF contiene identificación de piezas P1–P36; faltan cotas funcionales completas, tolerancias, espesor confirmado y archivo de corte editable (DXF/SVG/CAD). Se conserva como referencia original, sin afirmar que satisface por sí solo todos los requisitos de fabricación.
